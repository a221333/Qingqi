# 轻启 1.1：OneCommander 多选中键批量重命名

新版已在本机启动，已有开始菜单快捷方式和原有登录自启项已指向本文件夹中的 Qingqi.exe。原版程序和旧入口备份均保留。

## 使用

1. 在 OneCommander 的“经典／单一”布局中选中至少两个文件。
2. 松开 Ctrl、Shift 等修饰键，把鼠标停在文件列表内，按一下鼠标中键（滚轮按下）。
3. 在 File Automator 中设定规则，核对新旧文件名，再点击“处理”。只打开预览不会修改文件。

例如，选择 Simple rename，在文件命名规则中填写“资料_##”，勾选“将 # 转换为序号”，起始值设为 1，可预览“资料_01.txt、资料_02.txt……”；强制扩展名栏留空可保留原扩展名。

托盘右键菜单中的“OneCommander 多选中键重命名”用于开启或关闭入口。原有 Alt + Space 呼出、搜索、管理和个人配置继续使用。

## 适用范围

已实测 OneCommander 3.108.0.0 的经典单文件面板。双文件面板保持原中键行为；分栏布局尚未适配。程序不读取或改写剪贴板，也不自动点击“处理”。请按普通权限运行轻启和 OneCommander。

本文件夹是当前快捷方式和自启项指向的位置，请保留其路径。复制程序到其他目录可作为便携版运行，但不会自动改写现有入口。

## 回退

本机需要恢复旧版时，运行 RestorePrevious.cmd；它使用 previous-entrypoints.json 和同目录的旧入口备份恢复快捷方式、自启项，并启动旧程序。原有软件配置保留。回退脚本的语法、备份文件和旧程序存在性已检查，尚未实际执行回退。
